# Best Practice

> [!NOTE]
> Please note that due to the updating of this part of the documentation, some information is only valid for previous versions of OpenDXP.

First of all, OpenDXP is more or less a standard Symfony application, so most of the [Symfony 
best-practices](https://symfony.com/doc/current/best_practices.html) also apply for OpenDXP. 
It's highly recommended to have a detailed look at them before you deploy a OpenDXP application to production. 

This section documents definable topics or stories which are too unique or special to fit into the main documentation tree.
In many implementations of OpenDXP our partners and community develop features, which can also be useful for other implementations.
The OpenDXP core team will release new articles on a regular basis as well.
